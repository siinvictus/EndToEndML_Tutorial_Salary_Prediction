About the project

This project explores salary regression using exam score and years of experience. It covers data exploration, model training and comparison, experiment tracking, testing, and deployment, with examples including linear regression, Ridge, Lasso, and Elastic Net.

The tutorial is designed for readers with basic Python skills and a high-school mathematics background. Explore the tutorial repository.
